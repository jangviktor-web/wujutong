# 07 · 智識譜系（吳鞠通）

> 範圍：基於《溫病條辨》原序/凡例/雜說、《溫熱經緯》（王孟英輯＋吳鞠通按）、《醫醫病書》、《吳鞠通傳》交叉提煉。
> 目的：定位吳鞠通在溫病學派傳承鏈條中的「上游—本體—下游」坐標。

---

## 一、受誰影響（思想上游）

### 1. 啟蒙／師承
- **張仲景（張長沙，醫聖）**：父病→購方書→讀「外逐榮勢，內忘身命」而棄舉業專事方術的核心精神觸發者；視《玉函經》為「後世醫學之祖」，自述「蓋張長沙悲宗族之死，作《玉函經》」；仿《傷寒論》作法著《溫病條辨》。
- **汪瑟庵（汪文端公，山陽同鄉前輩）**：精神導師與催稿人。「醫非神聖不能」之論即出自汪氏（汪本人為山陽參知，後歿）；汪氏以「來歲己未濕土正化，二氣中溫厲大行，子盍速成是書」促其六年落筆，《溫病條辨》之成與汪氏直接相關。

### 2. 核心經典（思想源頭）
- **《內經》《靈樞》《難經》**：「乃知其源之所出」；原病篇逐條引《素問·六元正紀大論》《陰陽應象大論》《熱論》《刺熱》《金匱真言》立論。
- **《神農本草經》《傷寒論》《金匱要略》（合稱《玉函經》三種）**：「知醫學莫先於此，乃專力焉」；六經由表入裏為「橫看」，三焦由上及下為「豎看」，「與《傷寒論》為對待文字，有一縱一橫之妙」。
- **《周易》**：「深明大《易》之道者知之」；用《易》「陽大陰小」「泰否」「履霜堅冰」論陽氣；凡例稱「與大《易》相為表裏」。

### 3. 直接催生溫病學體系的前賢
- **葉天士（葉香岩）**：吳氏自承「師其意」。「持論平和，立法精細」——溫病條辨之衛氣營血、三焦辨治實由葉氏脫胎；《溫熱經緯》收葉氏三篇（外感溫熱、三時伏氣外感），吳鞠通逐節作按。批評：葉氏「不識燥證」、「誤用桑白皮」、「立論甚簡，醫案散見，人多忽之」。
- **吳又可（吳有性）**：在京師四庫館校書時得《溫疫論》，「觀其議論宏闊，實有發前人所未發，遂專心學步」；亦為《溫病條辨》「上承」源頭之一。批評：立論不精、立法不純、用力良苦而學術未精。
- **沈目南（沈明宗，明人）**：吳氏稱其為「唐宋以後唯一識燥證之勝氣者」；秋燥勝氣論據其說補成。
- **喻嘉言**：清代溫病學先驅，方法「亦不備」，然立論較張景岳有分析；批評其「中篇亦混入傷寒少陰、厥陰證，出方亦不能外辛溫發表、辛熱溫裏」。

### 4. 影響其思維框架的其他人物／流派（取捨並列）
- **王安道（王履，《溯洄集》）**：肯定其「始能脫卻傷寒，辯證溫病」，惜其論未詳、立法未備。
- **劉守真（劉完素）**：寒涼派祖師；吳氏取其「溫病當用寒涼」之大方向，但批其繼承者張子和「專用寒涼」未敢至極。
- **李東垣（補土派）／朱丹溪（滋陰派）／張景岳（溫補派）／陶氏《六書》**：吳氏總評「可閱而不可讀，以皆有倚於一偏之弊」，明確反對丹溪「陽常有餘陰常不足」之說（視為「殺人無算」之流毒），亦反張景岳之溫補混治。
- **錢仲陽（錢乙）／陳文中／薛立齋**：治痘明家；影響其《解兒難》《痘證》諸篇。
- **孫真人（孫思邈）／張隱菴（張志聰）《本草崇原》**：吳氏自述「仲景以下，惟孫真人論八脈、張隱菴《本草崇原》、葉氏《臨證指南》可觀」。

## 二、影響誰（思想下游）

### 1. 同代／直接傳人
- **王孟英（王士英）**：王氏輯《溫熱經緯》大量收入吳鞠通按語，吳按與章虛谷按雙線並列——吳對王而言既是先路（醫案序明言「下導王孟英之先路」），王對吳而言則是遺緒保存者。
- **蔣湖書屋主人**（即胡沄，吳氏摯友兼私淑弟子）：親炙後請吳氏著《醫醫病書》，自述「身受時醫補陰之誤」而促成；其體質與醫案為吳氏臨床反證（《醫醫病書》序中詳述）。
- **朱士彥（寶應）**：吳氏摯友、知音；晚年「嘆醫之謬妄，欲為《醫醫病書》」即向朱氏出稿相示；朱氏撰《吳鞠通傳》並為《醫醫病書》作題詞。
- **莫寶齋（莫尚書，紹興）**：越人世家，與吳氏交最密，紹興期間「或往莫家，或居趙園」；其痰飲病為吳氏親治驗案。
- **任濟堂（任九先生，紹興）**：紹城名醫，與吳氏「討論古今醫籍，心心相印」；獨讚《解兒難》《解產難》「多發前人所末發」。
- **顧南雅先生**：染燥疫經吳氏治癒，贈楹帖「具古今識藝斯進，真世俗見功乃神」。
- **次子廷芷／婿周宗信**：「庶乎守君之教」（《吳鞠通傳》）。

### 2. 後學／輯傳者
- **章虛谷（《醫門棒喝》）**：曾譏吳氏書缺誤，其按語卻大量被《溫熱經緯》採錄；吳、章二家在經緯中按語並列，客觀形成清代溫病學主要注釋譜系。
- **金月笙（金德僧／金謹齋）**：輯錄《吳鞠通醫案》原稿分為五卷排印行世，是醫案存世的關鍵傳人。
- **何廉臣**：錄存《醫醫病書》原書七十六則。
- **曹炳章（民國）**：增訂《醫醫病書》為上下兩卷／四編八十一則，並逐條加按；黃壽袞（圃人）為之作序。
- **汪曰楨（烏程）**：以「活人妙術，司命良箴，不偏不易，宜古宜今」贊《溫熱經緯》，延續吳氏系譜。
- **臨海郟芷谷**：得針法於天台山僧，吳氏引薦至蔣湖書屋主人；惜甲申年早卒，針法失傳（吳氏自嘆「深悔未曾習其傳」）。

### 3. 流傳影響
- 清末民國溫病學主流（民國中醫學校教材）：三焦辨證框架幾乎全承吳氏。
- 當代中醫溫病學教材：以葉桂「衛氣營血」＋吳鞠通「三焦辨證」並列為溫病辨證兩大綱領。
- 銀翹散、桑菊飲、安宮牛黃丸、犀角地黃湯、復脈湯系（加減復脈、救逆、貞元）、專翕膏、增液湯、新加黃龍……等方至今臨床沿用。

## 三、在思想地圖上的位置

### 1. 流派定位
- **溫病四大家之一**（葉天士、薛生白、吳鞠通、王孟英）。
- **三焦辨證體系創建者**：以「上—中—下」三焦縱貫取代／補充《傷寒論》之六經橫看；吳氏自定位「與《傷寒論》為對待文字，有一縱一橫之妙」。
- **溫病學派集大成者**：吳氏自述「諸賢如木工鑽眼已至九分，瑭特透此一分作圓滿會耳」——自視為葉天士、吳又可、沈目南、喻嘉言之「補完者」而非開創者。
- **氣運學派／寒溫統一論者**：明確「唐以後名醫之法，可採而不可宗」——所有門戶皆不可專執，六氣全備方為醫道。

### 2. 對比坐標（同代／歷史）
| 對象 | 關係 | 立場交集／分歧 |
|---|---|---|
| **葉天士** | 私淑師承 | 師其意（衛氣營血＋三焦），補其不備（燥證、產兒、方藥條理化） |
| **吳又可** | 學步並超越 | 上承其溫疫論，下駁其雜駁（「諍臣」自任） |
| **喻嘉言** | 借鑒批評 | 肯定其立論清明，批其辛溫治溫 |
| **張景岳** | 明確對立 | 斥其「以溫病即傷寒」混治 |
| **朱丹溪** | 明確對立 | 斥「陽常有餘陰常不足」為殺人元凶，倡「陽大陰小、扶陽抑陰」 |
| **李東垣** | 有限肯定 | 補中益氣「脫胎於建中」，未若建中沖和 |
| **薛生白** | 同道並尊 | 同為溫病四大家，濕熱病篇各立門庭 |
| **王孟英** | 直接嫡傳 | 經緯中吳氏按語與章虛谷並列 |
| **章虛谷** | 對手亦傳人 | 棒喝中譏其缺誤，經緯中又大量採其按 |

### 3. 學術爭議／被詰問處
- **立方過重之弊**：醫案何時跋序中提「惜立方有流於過重者，學之不善，生命攸關」——指石膏一斤、紫雪二兩、牛黃丸二十餘丸之運用需精察病情。
- **體例之議**：任濟堂批其「自條自辨，著書無此成例」；章虛谷《醫門棒喝》譏其「缺誤處甚多」。
- **寒涼派定位之辯**：史家或以吳氏歸於「寒涼派」（因大量用石膏、犀角），吳氏實主張「中無定體」——藥之多寡視病之輕重，反對「病重藥輕」「病輕藥重」。

### 4. 對西醫／現代醫學的態度
- **未見直接論述**：《醫醫病書》《溫病條辨》《醫案》三書六千餘頁未出現「西醫」「泰西」「解剖」等詞語。
- **「西人」「洋參」非西醫知識**：「洋參／西洋參」係進口藥名（如治趙氏伏暑用石膏一斤以上，西洋參做配伍）；「余治西人李姓布賈熱病」指病人族屬為西方商人，非涉西醫學。
- **時代背景**：吳氏活躍於 1793–1838（道光十六年歿），解剖學尚未系統傳入中土，西醫東漸要到鴉片戰爭之後（1839 後）。
- **立場推定**：資料闕如處置為「未接觸／無記載」，不可強解為「排斥」或「接受」；吳氏對任何外來學說均持「驗之於臨床」態度（治西人亦然），如西醫於其時代傳入，預設其可能採取同一「驗病然後用」立場。

> **關鍵提煉**：吳鞠通不是溫病學的「開山」而是「集大成＋補缺」——他把葉天士散見醫案中「衛氣營血」的精神，補上「三焦」縱貫骨架；吸納吳又可溫疫論、沈目南燥論、喻嘉言清議論、王安道脫傷寒說；以《內》《難》《傷寒》為體，以臨床驗病為用，最終完成溫病學「寒溫統一、六氣全備」的體系。
