# 吴鞠通温病诊断公式体系（10 个核心公式 + 决策树）

> **性质**：V3.5 Phase B 增量（2026-08-09）；将吴鞠通三焦辨证、卫气营血辨证、季节辨证、温病补充方剂矩阵 系统化为可执行公式。

## 一、10 个核心诊断公式

### 公式 1：上焦卫分定位（辛凉平/轻剂）

```
症状：发热 + 微恶风寒 + 咳嗽 + 口微渴 + 脉浮数 + 舌边尖红
   ↓
辨证：风温/温热初起（上焦卫分）
   ↓
治法：辛凉解表
   ↓
选方：
   IF 但咳 + 身不甚热 + 微渴   → 桑菊饮（辛凉轻剂）
   IF 发热重 + 咽痛 + 口渴     → 银翘散（辛凉平剂）
   IF 大汗 + 大渴 + 大脉       → 白虎汤（辛凉重剂）
```

**原文支撑**：温病条辨卷一·上焦篇·第 4-9 条

---

### 公式 2：上焦肺热咳喘

```
症状：身热 + 咳喘 + 汗出 + 口渴 + 脉数
   ↓
辨证：邪热壅肺（肺热咳喘）
   ↓
治法：清肺平喘
   ↓
选方：麻杏甘石汤
```

**原文支撑**：温病条辨上焦篇引《伤寒论》麻杏甘石汤证

---

### 公式 3：上焦神昏三宝选择（V3.5 关键鉴别）

```
症状：神昏谵语 + 高热
   ↓
IF 高热 + 舌红绛 + 烦躁不安         → 安宫牛黄丸（凉性最重，开窍力强）
IF 高热 + 痉厥 + 抽搐               → 紫雪丹（重镇痉厥）
IF 神昏 + 身热不扬 + 痰浊蒙蔽       → 至宝丹（化浊开窍）
   ↓
治法：清热开窍/熄风/化浊
   ↓
三宝均可配伍清宫汤送服
```

**原文支撑**：温病条辨卷一·第 16 条 / 安宫牛黄丸方论

---

### 公式 4：中焦气分热（白虎/承气）

```
症状：但发热不恶寒 + 反恶热 + 面赤 + 汗出 + 大渴 + 脉洪大
   ↓
辨证：阳明气分热
   ↓
IF 脉洪大 + 大汗 + 大渴         → 白虎汤（无形热盛）
IF 脉沉实 + 便闭 + 苔老黄       → 大承气汤（有形热结）
IF 脉滑数 + 便闭 + 苔黄         → 小承气汤（轻下）
IF 脉弦数 + 谵语 + 苔黄         → 调胃承气汤（缓下）
   ↓
禁忌：白虎四禁（脉浮弦细/沉/不渴/汗不出）
```

**原文支撑**：温病条辨卷二·中焦篇·第 1 条（白虎）、承气系列

---

### 公式 5：中焦湿温（三仁汤）

```
症状：头痛 + 恶寒 + 身重疼痛 + 苔白不渴 + 脉濡缓
   ↓
辨证：湿温初起（湿热并重，湿重于热）
   ↓
治法：宣畅气机、清热利湿
   ↓
选方：三仁汤（杏仁/白蔻/薏苡）
   ↓
禁忌：湿温三禁——禁汗/禁下/禁润
   ↓
加减：
   IF 热重于湿（苔黄腻 + 口渴） → 加黄连/栀子
   IF 湿重于热（苔白腻 + 不渴） → 加苍术/厚朴
```

**原文支撑**：温病条辨卷二·湿温禁例 + 三仁汤方论

---

### 公式 6：下焦营分热（清营汤）

```
症状：身热夜甚 + 心烦不寐 + 斑疹隐隐 + 舌绛 + 脉细数
   ↓
辨证：邪热入营（营分热盛）
   ↓
治法：清营透热
   ↓
选方：清营汤
   ↓
禁忌：舌白滑者忌用（湿邪未化，禁凉润）
```

**原文支撑**：温病条辨卷一·第 30 条 / 清营汤方论

---

### 公式 7：下焦血分热（犀角地黄汤）

```
症状：失血（吐血/衄血/便血/尿血）+ 斑色紫黑 + 舌深绛 + 躁扰不安
   ↓
辨证：热入血分（耗血动血）
   ↓
治法：凉血散瘀
   ↓
选方：犀角地黄汤
   ↓
加减：
   IF 高热 + 神昏             → 加安宫牛黄丸（凉开三宝）
   IF 痉厥 + 抽搐             → 加紫雪丹
```

**原文支撑**：温病条辨卷一·第 35-36 条 / 犀角地黄汤方论

---

### 公式 8：下焦阴伤（复脉法四阶）

```
症状：热邪深入下焦 + 脉虚大或结代 + 口干舌燥
   ↓
辨证：下焦真阴耗竭
   ↓
治法：滋阴复脉（步步深入）
   ↓
选方：
   IF 脉虚大 + 手足心热         → 加减复脉汤（一阶·基础）
   IF 下后大便溏 + 脉数        → 一甲复脉汤（二阶·防滑脱）
   IF 脉促 + 手足蠕动         → 二甲复脉汤（三阶·镇肝风）
   IF 脉虚大欲散 + 瘛疭神倦   → 三甲复脉汤（四阶·固脱）
   IF 神倦瘛疭 + 脉气虚        → 大定风珠（终阶·滋阴熄风）
```

**原文支撑**：温病条辨卷三·下焦篇·加减复脉汤系列 / 大定风珠方论

---

### 公式 9：季节温病定位（V3.5 增量）

```
季节 + 主症
   ↓
IF 春（初春） + 发热微恶风寒     → 风温（银翘散）
IF 春 + 发热不恶寒 + 口苦       → 春温
IF 春末夏初 + 大热大渴           → 温热（白虎汤）
IF 夏 + 高热 + 汗多 + 烦渴       → 暑温（新加香薷饮/清络饮）
IF 长夏（夏末秋初） + 身重 + 苔白 → 温湿（三仁汤）
IF 秋 + 干咳 + 鼻燥 + 咽干     → 秋燥（桑杏汤/清燥救肺汤）
IF 冬 + 发热 + 咳嗽 + 咽痛     → 冬温（银翘散加减）
IF 冬 + 腮肿/喉痛 + 高热       → 温毒（普济消毒饮）
```

**原文支撑**：温病条辨各卷首条文 + 温病补充.txt §一

---

### 公式 10：温病五死法预警（V3.5 关键安全公式）

```
温病危重指征 → 化源绝 → 死证
   ↓
IF 肺化源绝：汗涌 + 鼻扇 + 喘促       → 死（温病第 1 死法）
IF 心包化源绝：神昏 + 谵语 + 舌蹇     → 死（第 2 死法）
IF 脾化源绝：大热大渴 + 苔黑齿枯     → 死（第 3 死法）
IF 胃化源绝：便结旬余 + 攻下不通     → 死（第 4 死法）
IF 肝肾化源绝：脉虚欲绝 + 痉厥神倦 → 死（第 5 死法）
   ↓
处理：立即报告"危重指征"，需执业医师紧急介入
```

**原文支撑**：温病条辨卷一·第 11 条（"細按溫病死狀百端，大綱不越五條"）

## 二、5 维诊断决策树（症状→方剂）

> **使用**：当用户描述症状但未明确季节/温病类型时，按此决策树多维交叉定位。

```
[入口：主诉症状]
   │
   ├─ 发热 + 咳嗽为主 → 看季节 → 公式 9 → 风温/温热/秋燥
   │
   ├─ 高热 + 神昏为主 → 公式 3（三宝选择）
   │
   ├─ 高热 + 大渴为主 → 公式 4（中焦气分）
   │
   ├─ 高热 + 身重 + 苔白为主 → 公式 5（中焦湿温）
   │
   ├─ 身热夜甚 + 斑疹为主 → 公式 6/7（营血分）
   │
   ├─ 温病后期 + 脉虚 → 公式 8（下焦阴伤）
   │
   └─ 危重指征 → 公式 10（五死法预警）
```

## 三、卫气营血传变判断（温病传变规律）

```
温病传变路径：
   卫（表） → 气（里·热） → 营（里·深） → 血（里·最深）
   ↓
IF 发热 + 微恶寒 + 苔薄白          → 卫分（最浅）
IF 但发热不恶寒 + 反恶热 + 口渴    → 气分（已入里）
IF 舌绛 + 斑疹隐隐 + 心烦         → 营分（深入）
IF 舌深绛 + 失血/斑色紫黑         → 血分（最危）
   ↓
传变预警：
   IF 卫分治疗 1-2 天未效 + 出现口渴 → 警惕气传
   IF 气分高热 + 突现舌绛          → 警惕气传营（逆传心包）
   IF 营分 + 失血                  → 已入血分
```

**原文支撑**：温病条辨卷一·第 30 条（卫气营血辨证）
