# 吴鞠通·方证体系（V3.5 Agent2b 蒸馏稿）

> 來源：《温病条辨》（2039 行）＋《吴鞠通医案》（6371 行）。  
> 方法：以「三焦为纲、病名为目、卫气营血为纬」的方证思维。

---

## 一、核心方剂清单（22 首，分三焦）

### 【上焦·辛凉三阶】

**1. 银翘散（辛凉平剂）** ─ 连翘/银花各一两、桔梗/薄荷/牛蒡各六钱、竹叶四钱、生甘草五钱、芥穗四钱、淡豆豉五钱，鲜苇根汤煎。证：太阴风温「但热不恶寒而渴」，脉动数两寸独大。原文：「纯然清肃上焦，不犯中下，无开门揖盗之弊」（卷一·第 4 条，第 308 行）。案证常见：银翘散+减法治温病初起。

**2. 桑菊饮（辛凉轻剂）** ─ 杏仁二钱、连翘一钱五、薄荷八分、桑叶二钱五、菊花一钱、苦梗二钱、甘草八分、苇根二钱。证：太阴风温「但咳，身不甚热，微渴」。「咳，热伤肺络也……恐病轻药重，故另立轻剂」（第 6 条，第 315 行）。

**3. 白虎汤（辛凉重剂）** ─ 生石膏一两、知母五钱、生甘草三钱、白粳米一合。证：脉浮洪、舌黄、渴甚、大汗、面赤恶热。**四禁**：脉浮弦而细、脉沉、不渴、汗不出「皆不可与也」（第 7、9 条）。

**4. 清营汤（咸寒苦甘法）** ─ 犀角三钱、生地五钱、元参三钱、竹叶心一钱、麦冬三钱、丹参二钱、黄连一钱五、银花三钱、连翘（连心用）二钱。证：寸脉大、舌绛而干、反不渴（热在营中）；暑入手厥阴，夜寐不安、烦渴舌赤、时有谵语、目常开不闭。**禁**：「舌白滑者，不可与也」──湿重忌柔润（第 30 条，第 474 行）。

**5. 清宫汤（清膻中）** ─ 元参心/莲子心/竹叶卷心/连翘心/犀角尖/连心麦冬。证：温病误汗后神昏谵语；湿温邪入心包、神昏肢逆。「膻中为心之宫城也。俱用心者……即以清秽浊之品，便补心中生生不已之生气」（第 16 条，第 384 行）。

### 【上焦·凉开三宝】

**6. 安宫牛黄丸（最凉）** ─ 牛黄/郁金/犀角/黄连/朱砂/梅片/麝香/真珠/山栀/雄黄/金箔/黄芩，蜜丸一钱金箔为衣。证：邪入心包、舌蹇肢厥、神昏谵语。「芳香化秽浊而利诸窍，咸寒保肾水而安心体，苦寒通火腑而泻心用」（第 16 条）。

**7. 紫雪丹（次凉）** ─ 滑石/石膏/寒水石/磁石/羚羊角/木香/犀角/沉香/丁香/升麻/元参/炙草 + 朴硝/硝石 + 辰砂/麝香。证：热闭心包、神昏痉厥；暑入血分。案证：温病日久不解，「六脉全无……用紫雪丹续续灌醒，继以复脉汤收功」（案证第 113 行）。要语：「诸药皆降，独用一味升麻，盖欲降先升也」。

**8. 局方至宝丹（又次凉）** ─ 犀角/朱砂/琥珀/玳瑁各一两、牛黄/麝香各五钱 + 安息重汤炖化。证：湿温邪入心包、卒中秽浊神昏。「会萃各种灵异，皆能补心体，通心用」（第 16 条）。

### 【上焦·斑疹、湿温、暑温】

**9. 化斑汤（白虎加元参犀角）** ─ 石膏一两、知母四钱、生甘草三钱、元参三钱、犀角二钱、白粳米一合。证：太阴温病发斑；阳明斑者。「斑主以化斑汤专治肌肉；疹则用银翘散去豆豉加细生地丹皮大青叶倍元参方，主以芳香透络」（第 16 条）。

**10. 三仁汤（湿温祖方）** ─ 杏仁五钱、飞滑石六钱、白通草二钱、白蔻仁二钱、竹叶二钱、厚朴二钱、生薏仁六钱、半夏五钱；甘澜水八碗。证：头痛恶寒身重疼痛、舌白不渴、脉弦细而濡、面色淡黄、胸闷不饥、午后身热。**三禁**：汗之则神昏耳聋；下之则洞泄；润之则病深不解。「轻开上焦肺气，盖肺主一身之气，气化则湿亦化也」（第 43 条，第 530 行）。案证：汪室女「伏暑夹痰饮，三仁汤重加半夏、广皮……半月而愈」（案证 4649）。

**11. 新加香薷饮（辛温复辛凉）** ─ 香薷/银花/鲜扁豆花/厚朴/连翘。证：手太阴暑温形似伤寒、汗不出表实。「暑病不忌辛温者，以暑必兼湿」（第 24 条）。

**12. 清络饮（辛凉芳香）** ─ 鲜荷叶边/银花/西瓜翠衣/丝瓜皮/鲜竹叶心、鲜扁豆花。证：暑温发汗后头微胀目不了了；暑瘵加杏仁薏仁滑石；暑咳加甘桔甜杏仁麦冬知母。

**13. 生脉散（酸甘化阴）** ─ 人参/麦冬/五味子。证：手太阴暑温，汗多脉散大、喘喝欲脱。「酸甘化阴，守阴所以留阳」（第 26 条）。

### 【中焦·承气五方 + 湿热】

**14. 增液汤（咸寒苦甘，增水行舟）** ─ 元参一两、麦冬八钱（连心）、细生地八钱。证：阳明温病阴素虚；下后脉沉弱。「本方妙在寓泻于补，以补药之体，作泻药之用，既可攻实，又可防虚」──吴鞠通代吴又可承气养荣汤法（第 11 条，第 743 行）。案证（老年温病）：「议增液汤……保护老年有限津液，不比壮年可放心攻劫」（案证第 475 行）。

**15. 增液承气汤** ─ 增液汤 + 大黄三钱、芒硝一钱五。证：液干多热结少，下之不通，无水舟停。

**16. 宣白承气汤** ─ 生石膏五钱、生大黄三钱、杏仁粉二钱、栝蒌皮一钱五。证：喘促不宁、痰涎壅滞、右寸实大（脏腑合治）。

**17. 牛黄承气汤** ─ 安宫牛黄丸二丸化开 + 生大黄末三钱。证：邪闭心包、神昏舌短、饮不解渴（两少阴合治）。

**18. 新加黄龙汤** ─ 细生地五钱/生甘草二钱/人参一钱五/生大黄三钱/芒硝一钱/元参五钱/麦冬五钱/当归一钱五/海参二条/姜汁六匙。证：阳明温病应下失下、正虚不能运药（邪正合治，吴氏承气法最精彩处）。要语：「正气久耗而大便不下者，阴阳俱惫，尤重阴液消亡，不得再用枳朴伤气而耗液」。

**19. 三石汤** ─ 飞滑石/生石膏/寒水石/杏仁/竹茹/银花/金汁/白通草。证：暑温蔓延三焦，舌滑微黄，邪在气分（第 41 条）。

**20. 杏仁滑石汤（苦辛寒，湿热两解）** ─ 杏仁/滑石/黄芩/郁金/黄连/通草/厚朴/半夏。证：暑温伏暑三焦均受，舌灰白、胸痞闷、潮热呕恶、自利、溺短（第 42 条）。

### 【下焦·复脉法群】

**21. 加减复脉汤（甘润存津）** ─ 炙甘草六钱/干地黄六钱/生白芍六钱/麦冬五钱（不去心）/阿胶三钱/麻仁三钱。证：阳明久羁脉虚大手足心热甚于手足背；耳聋；六、七日不解脉尚躁盛。「复脉为热邪劫阴之总司也。乙癸同源也」（卷三·第 1、8 条）。

**22. 大定风珠（酸甘咸）** ─ 生白芍六钱/阿胶三钱/生龟板四钱/干地黄六钱/麻仁二钱/五味子二钱/生牡蛎四钱/麦冬六钱/炙甘草四钱/鸡子黄二枚/鳖甲四钱。证：神倦瘛疭、脉气虚弱、舌绛苔少、时时欲脱。「大队浓浊填阴塞隙，介属潜阳镇定」（第 16 条）。案证：富氏「巅顶一点痛，畏灯光日光如虎……定风珠三剂而愈」（案证第 6223 行）。

> 22 首之外：雪梨浆/五汁饮/玉女煎（去牛膝加元参）/桑杏汤/沙参麦冬汤/普济消毒饮（去升柴芩连）/益胃汤/清燥汤/青蒿鳖甲汤/连梅汤/椒梅汤/一甲·二甲·三甲复脉汤/小定风珠/专翕大生膏/犀角地黄汤/桃仁承气/抵当汤/栀子豉汤/茵陈蒿汤/二甲/三甲复脉汤等。

## 三、方剂加减法（按证型系统归纳）

### 1. 银翘散系列化裁（吴氏最示範）

- 胸膈闷 → 藿香、郁金（护膻中）；渴甚 → 花粉；项肿咽痛 → 马勃、元参
- 衄 → 去芥穗、豆豉，加白茅根、侧柏炭、栀子炭
- 咳 → 加杏仁；二三日热入里 → 加细生地、麦冬；小便短 → 加知母、黄芩、栀子

**伏暑变方（按舌色分层）**：  
舌白无汗 → 去牛蒡、元参，加杏仁、滑石（气分表实）  
舌赤无汗 → 加生地、丹皮、赤芍、麦冬（入营）  
舌白有汗 → 去牛蒡、元参、芥穗，加杏仁、石膏、黄芩（气分表虚）

### 2. 承气法五等 + 护胃承气

大承气（痞满燥实）/ 小承气（微满微实）/ 调胃承气（热结旁流）/ 增液汤（阴虚不可下）/ 增液承气（液干＋微热）/ 护胃承气（下后热退未尽，增液合大黄知母丹皮）。

### 3. 复脉法四阶（层层深入）

加减复脉（邪少虚多总司）→ 一甲复脉（加牡蛎，防泄阴）→ 二甲复脉（加牡蛎、鳖甲，手指蠕动，急防痉）→ 三甲复脉（加龟板，心中痛）→ 小定风珠（既厥且哕：鸡子黄、龟板、阿胶、童便、淡菜）→ 大定风珠（瘛疭欲脱，大队填阴）。

### 4. 三焦分治总则

上焦 → 银翘/桑菊/白虎/清营/清宫/三宝；中焦 → 承气辈/增液辈/三仁辈/藿朴辈/五加减正气散；下焦 → 复脉辈/青蒿鳖甲/连梅汤/椒梅汤/专翕大生膏。

## 四、方-证-人对应关系（吴鞠通式方证思维）

核心：「随其所在而攻之」「用药非丝丝入扣，不能中病」。

### 1. 三维定位法（三焦-卫气营血-脏腑）

- 上焦卫分（肺卫）：辛凉平/轻/重三阶（银翘→桑菊→白虎）
- 上焦气分（肺胃）：白虎/桑杏汤
- 上焦营血（心包）：清营汤→清宫汤+三宝
- 中焦气分（胃肠）：承气五方按痞满燥实阴虚分选
- 中焦营血：化斑汤/玉女煎/犀角地黄汤
- 下焦阴虚：复脉辈（乙癸同源）/青蒿鳖甲汤（先入后出）

### 2. 人-证-方临床辨证链（案证实录）

- **老年温病**（案证第 475 行）：「保护老年有限津液，不比壮年可放心攻劫」
- **小儿暑温**（案证 1009）：「脏腑薄，邪易过卫入营，惟以清营汤清营分之热而保津液」
- **产妇血虚**（案证 1786）：三大证（郁冒/痉厥/大便难）皆以三甲复脉、大小定风珠、专翕膏；「古人谓产后不怕虚寒，单怕虚热」
- **体瘦过服桂附致温**（案证 785）：调胃承气下十三次 → 复脉 7 帖 → 专翕膏半料

### 3. 五大核心原则

1. **三焦死法**：「肺化源绝」「心神内闭」「阳明太实」「脾郁发黄」「下焦津液涸」──决定攻补先后
2. **卫气营血传变**：在卫汗之可也，到气方可清气，入营犹可透热转气，到血只须凉血散血（承叶氏，吴氏以方落地）
3. **治上不犯中，治中不犯下**：银翘散「纯然清肃上焦，不犯中下」
4. **逐邪就近**：增液汤引邪出表、银翘汤从表透邪
5. **存阴退热、留人治病**：复脉法为热邪劫阴之总司

### 4. 同方不同证 vs 同证不同方（案证活法）

**同方不同证**─清营汤眼目「舌绛」：①暑入心包 ②小儿暑痫 ③大人暑痫（加勾藤、丹皮、羚羊角）④阳明温病舌黄燥肉色绛不渴。  
**同证不同方**─神昏分型：热闭谵语用安宫（王某案）；体厥脉厥灌醒用紫雪（案证 113）；湿温邪入心包用至宝（清宫汤加减送服）；阴亏欲脱用复脉辈；兼腑实用牛黄承气；卒中秽浊用至宝。

### 5. 核心案证（证-机-方-效四段链）
