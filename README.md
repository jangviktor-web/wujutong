## 🚀 核心能力（6 大支柱）

### 1️⃣ 三焦辨证思维
- **上焦**（肺/心包）：辛凉三阶 → 银翘散、桑菊饮、白虎汤
- **中焦**（脾胃/大肠）：清热存津 → 白虎、承气、增液
- **下焦**（肝/肾）：育阴潜阳 → 复脉、三甲、青蒿鳖甲
- 详见 `references/01-core-philosophy.md`

### 2️⃣ 卫气营血传变判断
- **卫分**（表）：发热微恶风寒 → 银翘散
- **气分**（里）：大热大渴大汗脉洪大 → 白虎汤
- **营分**（热入心包）：舌绛神昏 → 清营汤 + 安宫牛黄丸
- **血分**（耗血动血）：斑疹吐衄 → 犀角地黄汤
- 详见 `references/29-diagnostic-formulas.md`（10 个核心公式）

### 3️⃣ 22 首核心方剂体系
按三焦分群，覆盖温病全阶段。详见 `references/24-formula-pattern-system.md`。

### 4️⃣ 359 案医案库（最大特色）
- 45 个病证分类（原书卷一~卷五全收录）
- 每案独立 md 文件，含患者、年龄、诊治日、方药、加减
- **双索引速查**：
  - `_index.md`（按卷+病证组织）
  - `_quick-lookup.md`（**病机/三焦/方剂/症状** 4 维反查）

### 5️⃣ 临床安全层
- **温病五死法**（化源绝预警：肺之化源绝、心之化源绝、肝之化源绝、脾之化源绝、肾之化源绝）
- **白虎四禁**（脉浮弦而细、脉沉、口不渴、不汗出）
- **湿温三禁**（禁汗、禁下、禁润）
- **26 条误治急救方剂**
- 详见 `references/09-clinical-safety.md`

### 6️⃣ 跨流派对话能力
- 与 `nihaixia`（倪海厦·经方派）同台对话：同一病案，四回合交锋

## 🆚 经方派 vs 温病派（10 维思维差异）

> 同一病案：盛夏发热 39.2°C，微恶风寒 + 咽痛 + 口渴 + 脉浮数

| 维度 | 倪海厦（经方派） | 吴鞠通（温病派） |
|------|------------------|------------------|
| **辨证框架** | 六经辨证 | 三焦辨证 + 卫气营血 |
| **病因观** | 风寒/风热 | 温邪（挟湿/挟风/挟暑） |
| **邪入路径** | 太阳→阳明→少阳→太阴→少阴→厥阴 | 上焦→中焦→下焦（卫→气→营→血） |
| **治法核心** | 驱邪外出（汗/吐/下/和/温/清/补/消） | **存津液** + 逐秽清热 |
| **微恶风寒** | 表证未解（仍有麻桂适应） | 温邪在卫分（忌用辛温，宜辛凉平剂） |
| **汗法** | 麻黄汤峻汗、桂枝汤啜粥微汗 | 银翘散辛凉解肌（"治上如羽"） |
| **生津** | 多用甘温（甘草、干姜、大枣） | 多用甘寒（麦冬、生地、沙参） |
| **季节观** | 伤寒百病之始，不分季节 | 四季温病不同（春→风温/夏→暑温/秋→秋燥/冬→冬温） |
| **互批** | 批温病派"凉遏冰伏、引邪深入" | 批经方派"以火济火、为贼立帜" |
| **温病与伤寒** | 温病是伤寒的子类 | 温病是**羽翼伤寒**，补六经之未逮 |

### 🔥 一句话总结

> **倪海厦眼里是「邪气的出路」，吴鞠通眼里是「津液的存亡」。**
>
> 一个驱邪，一个护津。临床配合使用，可得双视角。

## 🩺 三焦辨证：温病学核心思维

吴鞠通在《温病条辨》开篇即确立**三焦为纲、卫气营血为目**的双层辨证体系：

### 三焦（病位）

| 病位 | 脏腑 | 典型症状 | 代表方 |
|------|------|----------|--------|
| **上焦** | 肺 / 心包 | 发热、咳嗽、咽痛、神昏 | 银翘散、桑菊饮、安宫牛黄丸 |
| **中焦** | 脾胃 / 大肠 | 大热、大渴、大汗、便秘 | 白虎汤、承气汤、增液汤 |
| **下焦** | 肝 / 肾 | 痉厥、癃闭、虚脱 | 复脉汤、三甲复脉、青蒿鳖甲汤 |

### 卫气营血（病程阶段）

| 阶段 | 病位 | 辨证要点 | 代表方 |
|------|------|----------|--------|
| **卫分** | 肺卫 | 发热微恶风寒、苔薄白 | 银翘散 |
| **气分** | 肺胃/肠 | 大热大渴大汗脉洪大 | 白虎汤、承气汤 |
| **营分** | 心包 | 舌绛、心烦不寐、斑疹隐隐 | 清营汤、安宫牛黄丸 |
| **血分** | 肝肾 | 斑疹透露、吐衄、痉厥 | 犀角地黄汤、羚角钩藤汤 |

### 传变规律

> **顺传**：上焦→中焦→下焦（卫→气→营→血）—— 病情渐进
>
> **逆传**：肺卫直传心包（卫分→营分）—— 病情凶险（吴鞠通首创"逆传心包"概念）

## 🛡️ 临床安全层（5 死法 + 31 条铁律）

### ⚠️ 温病五死法（化源绝预警）

吴鞠通最强调的临床警告：

1. **肺之化源绝**：肺气受灼、津液枯涸 → 喘喝欲脱
2. **心之化源绝**：热陷心包、神昏谵语、阴液消亡
3. **肝之化源绝**：肝风内动、痉厥、神倦瘛疭
4. **脾之化源绝**：脾阴枯涸、中气消亡
5. **肾之化源绝**：肾阴枯涸、虚风内动

### 🚫 白虎四禁（脉浮弦而细、脉沉、口不渴、不汗出）

> **"白虎汤是温病清气分大热的主方，但用错就是杀人。"**
>
> 吴鞠通在《温病条辨》上焦篇第 9 条专门立禁。

### 🚫 湿温三禁

> 1. **禁汗**（湿家忌汗，汗之则痉）
> 2. **禁下**（湿温未化燥不可下，下之则洞泄）
> 3. **禁润**（湿温未化热不可润，润之则病深不解）

## 🎭 角色扮演示例

### 示例 1：上焦温病（春初风温）

> **【用户】** 患者女，28 岁，3 月初受凉后发热 38.7°C，微恶风寒，咽痛 1 天，口微渴，舌尖红，脉浮数。该用经方麻黄汤还是时方银翘散？
>
> **【吴鞠通 · Skill】**
>
> 病在**上焦手太阴肺卫分**。春初风温，非伤寒也。
>
> - 伤寒：脉浮紧、恶寒重、无汗而喘 → **麻黄汤**（辛温发汗）
> - 风温：脉浮数、咽痛、口渴 → **银翘散**（辛凉平剂）
>
> 此案脉浮数 + 咽痛 + 口渴，三者具矣，风温无疑。麻黄汤以火济火，为贼立帜，**禁用**。
>
> 当予**银翘散**加减：
> - 银花 30g、连翘 30g（辛凉清热）
> - 薄荷 18g 后下（辛散透表）
> - 桔梗 18g、生甘草 15g（利咽解毒）
> - 牛蒡子 18g、淡豆豉 15g（解表利咽）
> - 芦根 30g（生津）
>
> 三日不解，进**白虎汤**（"治上焦如羽，非重不举"——但白虎汤力大，若银翘不解方可用之）。**白虎四禁**牢记：脉浮弦而细、脉沉、口不渴、不汗出，犯一禁即不可用。

### 示例 2：跨流派对比

> **【用户】** 同样病案，倪海厦会怎么开方？
>
> **【倪海厦 · Skill】**（同期加载）
>
> 六经辨证：**太阳阳明合病**。脉浮数 = 太阳未解；口渴咽痛 = 阳明内热已起。
>
> 当予**葛根汤**：葛根、麻黄、桂枝、白芍、甘草、大枣、生姜。
>
> 微汗出则太阳解，阳明亦降（葛根专解阳明经热）。
>
> > 注：倪海厦认为温病初起仍可用葛根汤解肌，与吴鞠通"忌汗"观点根本分歧——倪氏认为"汗出热退"是邪有出路，吴氏认为"汗出伤津"是助热。
