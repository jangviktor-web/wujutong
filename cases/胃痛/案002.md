# 胃痛 · 案 002

- **患者**：伊氏
- **病证**：胃痛
- **代表方**：（待录）
- **原文摘录**：

```
**【伊氏】** 三十歲 **甲子十月二十七日** 脈弦急，脅脹攻心痛，痛極欲嘔，甫十五日而經水暴至甚多，幾不能起，不欲食，少腹墜脹而痛。此怒郁傷肝，暴注血海，肝厥犯胃也，議胞宮陽明同治法。蓋《金匱》謂胞宮累及陽明，治在胞宮；陽明累及胞宮，治在陽明。茲因肝病下注胞宮，橫穿土位，兩傷者兩救之。仍以厥陰為主，雖變《金匱》之法，而實法《金匱》之法者也。

制香附〈（三錢）〉　烏藥〈（二錢）〉　半夏〈（五錢）〉　艾炭〈（三錢）〉　鬱金〈（二錢）〉　黃芩炭〈（一錢）〉　小茴炭〈（二錢）〉　血餘炭〈（三錢）〉　青皮〈（八分）〉　五靈脂〈（錢半）〉
```
