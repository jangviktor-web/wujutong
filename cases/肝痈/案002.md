# 肝痈 · 案 002

- **患者**：謝
- **病证**：肝痈
- **代表方**：（待录）
- **原文摘录**：

```
**【謝】** 四十四歲 **辛巳三月二十四日** 病起肝鬱脅痛，痰中帶血，病名肝著。醫者不識絡病因由，與絡病治法，非見血投涼，即見血補陰，無怪乎愈治愈窮也。大凡血症之脈，左脈堅搏，治在下焦血分；右堅搏，治在上焦氣分。茲左手脈浮取弦，沉取洪大而數，重按即芤，前曾痰有氣味，現在痰挾瘀滯黑色，唇舌皓白，其為肝經絡瘀挾痰飲，咳血無疑。勢已憊極，勉與宣絡止血，兼之兩和肝胃，以逐痰定咳。〈（方此未服）〉

新絳紗〈（三錢）〉　旋覆花〈（三錢）〉　歸鬚〈（錢半）〉　桃仁泥〈（三錢）〉　半夏〈（三錢）〉　廣皮炭〈（二錢）〉　蘇子霜〈（一錢）〉　降香末〈（錢半）〉　廣鬱金〈（二錢）〉
```
