## 案002

- **患者**：金

```
**【金】** 男 四歲 幼孩手心熱，舌苔厚濁，嘔吐，食積也，法當和胃而醒脾，宜降不宜升。

## 案003

- **患者**：陶
- **代表方**：（待录）

```
**【陶】** 二歲 乙酉七月初二 幼童手心熱甚，舌微黃，身微熱，體瘦，神不足，防成疳疾，與疏補中焦，兼之消食。

```

## 案004

- **患者**：孫
- **代表方**：（待录）

```
**【孫】** 九歲 **丁亥七月二十五日** 疳疾已久，若不急講調理飲食，則不可為矣，用藥以疏補中焦立法。
