# 痘症 · 案 008

- **患者**：徐男
- **病证**：痘症
- **代表方**：（待录）
- **原文摘录**：

```
**【徐男】** 六歲 **癸亥臘月初四日** 重險痘三天，骨立無肉，血枯而燥，乾紅色暗，黏連成片，皆隱在皮中，乃梟毒把持之故，勉議兩解重法。如照常理立方，恐鞭長莫及。

```
