# 少阳瘛疭 · 案 002

- **患者**：某氏
- **病证**：少阳瘛疭
- **代表方**：間服紫雪丹及牛黃丸
- **原文摘录**：

```
**【某氏】** 己卯七月 其人本有肝風頭痛病根，少陽鬱勃，真水不能上濟可知。又現伏暑內發，新涼外加，金來剋木，木愈病矣。少陽所至為瘛瘲，理固然也。勉與清膽絡，兼清心包。

犀角〈（三錢）〉　丹皮〈（五錢）〉　鮮荷葉〈（一張，去蒂）〉　羚羊角〈（三錢）〉　細生地〈（五錢）〉　鉤藤〈（二錢）〉　茶菊花〈（三錢）〉　桔梗〈（二錢）〉　甘草〈（錢半）〉　桑葉〈（三錢）〉
```
