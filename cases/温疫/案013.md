# 温疫 · 案 013

- **患者**：甘
- **病证**：温疫
- **代表方**：（待录）
- **原文摘录**：

```
**【甘】** 五歲 **壬申年六月十八日** 溫熱七日不退，渴思涼飲，脈仍洪浮而長，急宜辛涼退熱，加入芳香化濁，最忌羌防柴葛發表。腹痛者，穢濁也。勿認作寒，用溫藥。

連翹〈（六錢）〉　牛蒡子〈（三錢）〉　銀花〈（六錢）〉　石膏〈（六錢）〉　廣鬱金〈（三錢）〉　藿香葉〈（三錢）〉苦桔梗〈（六錢）〉　豆豉〈（三錢）〉　知母〈（二錢）〉　人中黃〈（二錢）〉　黃芩〈（二錢）〉　丹皮〈（二錢）〉
```
