# 温疫 · 案 022

- **患者**：趙
- **病证**：温疫
- **代表方**：（待录）
- **原文摘录**：

```
**【趙】** 五十五歲 **癸丑年六月二十六日** 體瘦無子，過服桂、附，津液枯燥。於二十二日得溫熱，自服補中益氣湯三帖，致邪無出路，服辛涼輕劑二帖，竹葉石膏湯三帖，至七月初二日，煩躁不寐，並不臥床，赤身滿地混抓，譫語乾熱，無汗舌黃，與調胃承氣湯，加元參一小劑，得大便少許，隨出赤紅疹數十枚，少安半日，其症如前，與沃陰之甘涼法。二三日大躁大狂，又與調胃承氣湯一小帖。又出疹數十枚，又少安，熱總不退，脈總不靜。如是者前後共下十三次，出疹十三次。而後脈靜身涼，服復脈湯七帖後作專翕大生膏半料，計十二斤，半年後始復原。此證原案已失，舉其大略，以備一格。
```
