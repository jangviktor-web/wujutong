## 案007

- **患者**：孫
- **代表方**：（待录）

```
**【孫】** 四十五歲 **乙丑六月初六日** 頭痛，左關獨高，責之少陽內風掀動，最有損一目之弊。若以為外感風寒，則遠甚矣。議清少陽膽絡法。再此症除左關獨高，餘脈皆緩，所謂通體皆寒，一隅偏熱，故先清一隅之熱。《金匱》謂先治新病，舊病當後治也。
```

## 案010

- **患者**：鞠通
- **代表方**：（待录）

```
**【鞠通】** 自醫，**丁巳六月十三日**，時年四十歲。

先暑後風，大汗如雨，惡寒不可解，先服桂枝湯一帖。為君之桂枝用二兩，盡劑毫無效驗。次日用桂枝八兩，服半劑而愈。
```
