# 咳嗽 · 案 008

- **患者**：陳
- **病证**：咳嗽
- **代表方**：（待录）
- **原文摘录**：

```
**【陳】** 四十歲 **丙戌正月十三日** 咳嗽起於前年九月，夏傷於濕，伏暑遇新涼而發之咳，症本不大，後因誤補封固，邪已難出。又用桑皮末用地骨引邪入腎。按腎為封藏之臟，誤入者永難再出矣。身熱得補藥汗解，而足心之熱總不解，是其確證也。現在咳而嘔，六脈弦細而數，陰陽兩虛也。勉照胃咳方法，先能得谷，建立中焦，假如胃旺，或有生機。常吐血一二口，中有瘀滯，亦系久病絡傷，季脅作痛，肝經部分應加宣絡降氣。

姜半夏〈（六錢）〉　蘇子霜〈（錢半）〉　桃仁〈（三錢）〉　雲苓〈（八錢，嘔不止可加至兩許）〉　降香末〈（二錢）〉　廣皮炭〈（三錢）〉　薑汁〈（每杯沖三小杯）〉
```

> 完整诊治记录见《吴鞠通医案》卷[待核对] · 咳嗽 · 第 008 案。
