# 肿胀 · 案 002

- **患者**：陳
- **病证**：肿胀
- **代表方**：脾主散
- **原文摘录**：

```
**【陳】** 三十二歲 **甲寅年二月初四日** 太陰所至，發為䐜脹者，脾主散津液，脾病不能散津，土曰敦阜，斯䐜脹矣。厥陰所至，發為䐜脹者，肝主疏泄，肝病不能疏泄，木穿土位，亦䐜脹矣。此症起於肝經鬱勃，從頭面腫起，腹因脹大，的系蠱脹，而非水腫，何以知之。滿腹青筋暴起如蟲紋，並非本身筋骨之筋，故知之。治法行太陽之陽，泄厥陰之陰為要，醫用八味丸誤治，反攝少陰之陰，又加牡蠣澀陰戀陽，使陽不得行，而陰凝日甚，六脈沉弦而細，耳無所聞，目無所見，口中血塊累累續出，經所謂血脈凝泣者是也。勢太危極，不敢驟然用藥，思至陽而極靈者，莫如龍，非龍不足以行水，而開介屬之翕，惟鯉魚三十六鱗能化龍，孫真人曾用之矣。但孫真人《千金》原方去鱗甲用醋煮，茲改用活鯉魚大者一尾，得六斤不去鱗甲，不破肚，加蔥一斤，姜一斤，水煮熟透，加醋一斤，任服之。

服鯉魚湯一晝夜，耳聞如舊，目視如舊，口中血塊全無，神氣清爽，但腫脹未除。
```
