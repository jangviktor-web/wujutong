# 肿胀 · 案 006

- **患者**：陳
- **病证**：肿胀
- **代表方**：（待录）
- **原文摘录**：

```
**【陳】** 二十六歲 **乙酉年五月十五日** 脈弦細而緊，不知飢，內脹外腫，小便不利，與腰以下腫當利小便法，陽欲滅絕，重加熱以通陽，況今年燥金，太乙天符，經謂必先歲氣，毋伐天和。

桂枝〈（六錢）〉　豬苓〈（五錢）〉　生茅朮〈（三錢）〉　澤瀉〈（五錢）〉　廣橘皮〈（三錢）〉　川椒炭〈（五錢）〉厚朴〈（四錢）〉　茯苓皮〈（六錢）〉　公丁香〈（二錢）〉　杉木皮〈（一兩）〉
```
