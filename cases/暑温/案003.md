# 暑温 · 案 003

- **患者**：周
- **病证**：暑温
- **代表方**：（待录）
- **原文摘录**：

```
**【周】** 五十二歲 **壬戌年七月十四日** 世人悉以羌防柴葛，治四時雜感，竟謂天地有冬而無夏，不亦冤哉！以致暑邪不解，深入血分成厥，衄血不止，夜間煩躁，勢已膠錮難解，焉得速功。

鮮蘆根〈（一兩）〉　丹皮〈（五錢）〉　荷葉邊〈（一張）〉　羚羊角〈（三錢）〉　元參〈（五錢）〉　杏仁〈（三錢）〉桑葉〈（三錢）〉　滑石〈（三錢）〉　犀角〈（三錢）〉　細生地〈（五錢）〉
```

> 完整诊治记录见《吴鞠通医案》卷[待核对] · 暑温 · 第 003 案。
