# 暑温 · 案 009

- **患者**：廣
- **病证**：暑温
- **代表方**：（待录）
- **原文摘录**：

```
**【廣】** 二十四歲 **七月二十二日** 六脈洪大之極，左手更甚，目斜視，怒氣可畏，兩臂兩手，捲曲而瘛瘲，舌斜而不語三四日，面赤身熱，舌苔中黃邊白，暑入心包膽絡，以清心膽之邪為要，先與紫雪丹。

桑葉〈（三錢）〉　羚羊角〈（三錢）〉　細生地〈（五錢）〉　連翹〈（五錢，連心）〉　竹茹〈（三錢）〉　銀花〈（五錢）〉　丹皮〈（三錢）〉　嫩荷葉〈（一張）〉　天冬〈（三錢）〉　麥冬〈（五錢）〉　犀角〈（三錢）〉
```

> 完整诊治记录见《吴鞠通医案》卷[待核对] · 暑温 · 第 009 案。
