# 暑温 · 案 012

- **患者**：俞
- **病证**：暑温
- **代表方**：（待录）
- **原文摘录**：

```
**【俞】** 男 三歲 **七月初二日** 暑濕傷脾，暮夜不安，小兒脈當數，且少腹以下常腫痛，肝腎亦復虛寒；況面色青黃，舌苔白，手心時熱，調理乳食要緊，防成疳疾。議腑以通為補，食非溫不化例。

```
