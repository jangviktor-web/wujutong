## 案004

- **患者**：龔
- **代表方**：（待录）


## 案005

- **患者**：普
- **代表方**：用虎杖散

```
**【普】** 三十八歲 小便淋濁，莖管痛不可忍，自用五苓、八正、萆薢分清飲等滲濕，愈利愈痛。細詢病情，由房事不遂而成。余曰：溺管與精管異途，此症當治精管為是。用虎杖散法，現無虎杖草，以杜牛膝代之。

杜牛膝〈（五錢）〉　當歸〈（三錢）〉　降香末〈（三錢）〉　麝香〈（五釐）〉　桃仁泥〈（三錢）〉　兩頭尖〈（三錢）〉　琥珀〈（六分）〉　丹皮〈（三錢）〉
```
