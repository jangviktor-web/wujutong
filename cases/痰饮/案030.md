# 痰饮 · 案 030

- **患者**：趙
- **病证**：痰饮
- **代表方**：與局方消暑丸
- **原文摘录**：

```
**【趙】** 四十六歲 正月三十日 太陽痹則腰脊痛，或左或右，風勝則引也。或喘或不喘者，中焦流飲，上泛則喘，不泛則不喘也。切戒豬肉生冷，與一切補藥，周年可愈。六脈洪大已極，石膏用少，萬不見效，命且難保。

生石膏〈（六兩）〉　雲苓皮〈（五錢）〉　白通草〈（一錢）〉　桂枝〈（五錢）〉　半夏〈（五錢）〉　黃柏炭〈（二錢）〉　杏仁〈（五錢）〉　小枳實〈（五錢）〉　生苡仁〈（五錢）〉　防己〈（四錢）〉
```

> 完整诊治记录见《吴鞠通医案》卷[待核对] · 痰饮 · 第 030 案。
