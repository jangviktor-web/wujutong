# 中燥 · 案 004

- **患者**：李
- **病证**：中燥
- **代表方**：（待录）
- **原文摘录**：

```
**【李】** 四十六歲 **乙酉四月十六日** 胃痛脅痛，或嘔酸水，多年不愈，現在六脈弦緊，皆起初感燥金之氣，金來剋木，木受病，未有不剋土者。土受病之由來，則自金剋木始也，此等由外感而延及內傷者，自唐以後無聞焉。議變胃而受胃變法，即用火以剋金也。又久病在絡法：

公丁香〈（一錢）〉　茯苓〈（五錢）〉　枳實〈（四錢）〉　川椒炭〈（三錢）〉　苡仁〈（五錢）〉　生薑〈（五錢）〉　半夏〈（五錢）〉　陳皮〈（三錢）〉
```

> 完整诊治记录见《吴鞠通医案》卷[待核对] · 中燥 · 第 004 案。
