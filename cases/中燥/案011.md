# 中燥 · 案 011

- **患者**：鄭
- **病证**：中燥
- **代表方**：（待录）
- **原文摘录**：

```
**【鄭】** 二十六歲 先是三月初九日，得太陽中風，與桂枝湯已愈。十二日晚已臥，下身有微汗，因廚房不戒於火，只穿小汗褂一件，未著襪，出外救火，火熄復臥，覺身微熱惡寒，腹中脹痛，脈弦數，與桂枝柴胡各半湯，汗出稍輕，究不能解。以後外雖化熱，面赤汗多如溫病狀，以當臍之痛未休，舌白不燥，斷不敢用辛涼，而辛溫之藥，或進或退，十日不解。至二十四日反重用溫熱，佐以黃連三錢，次日表證里證，一齊俱解如失。後與調理脾胃兩陽而安。
```

> 完整诊治记录见《吴鞠通医案》卷[待核对] · 中燥 · 第 011 案。
